# Auspify Task 4: Trend Analysis by Release Year

## 1. Project Overview
This project analyzes Netflix content by release year to understand historical trends in movies and TV shows.

## 2. Objectives
- Calculate the number of titles by release year.
- Compare movies and TV shows over time.
- Identify years with the highest number of titles.
- Calculate year-over-year changes.
- Visualize historical release patterns.

## 3. Tools and Technologies
- Python
- Pandas
- Matplotlib

## 4. Methodology
1. Load the Netflix dataset.
2. Remove duplicate records.
3. Clean and validate release-year values.
4. Calculate yearly content counts.
5. Compare movies and TV shows by release year.
6. Calculate yearly changes and growth percentages.
7. Generate charts and business insights.

## 5. Deliverables
- Yearly content trend report
- Movie and TV Show breakdown
- Overall release-year trend chart
- Content-type trend chart
- Business insights summary

## 6. Conclusion
This project demonstrates how Python can be used to analyze historical content patterns and visualize changes in Netflix titles by release year.

## 7. Limitation
Release year indicates when a title was released, not when it was added to Netflix. Recent years may have incomplete data, so apparent declines should be interpreted cautiously.
