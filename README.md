# auspify-netflix-trend-analysis-task-4
Netflix release-year trend analysis using Python, Pandas, and Matplotlib, with yearly content statistics and visualizations.
# Auspify Task 4: Netflix Trend Analysis by Release Year

## Overview
This project analyzes Netflix titles by release year to explore historical content patterns and compare Movies with TV Shows.

## Objectives
- Calculate yearly content releases.
- Identify peak release years.
- Compare Movies and TV Shows.
- Calculate year-over-year changes.
- Visualize release-year trends.

## Technologies
- Python
- Pandas
- Matplotlib

## Project Structure
- `trend_analysis.py` — analysis script
- `FINAL_REPORT.md` — project report
- `output/yearly_content_trends.csv` — yearly statistics
- `output/yearly_content_by_type.csv` — content-type breakdown
- `output/yearly_release_trend.png` — overall trend chart
- `output/content_type_trends.png` — Movies vs TV Shows chart
- `output/business_insights.txt` — summary of findings

## How to Run
Install the required libraries:

`python -m pip install pandas matplotlib`

Place the Netflix dataset in the project folder as `Dataset.csv`, then run:

`python trend_analysis.py`

## Conclusion
This project demonstrates data cleaning, time-based analysis, and visualization using Python. Release year represents a title's release year, not necessarily the date it was added to Netflix.
